# 디렉팅팀 → 제작팀: 상세페이지 연출컷 후속 제작 방향

- 테스트 ID: SCENE-ORBO-S1-20261023-01
- 날짜: 2026-10-23 (한국 시간)
- 발신: 디렉팅팀
- 수신 대상: 제작팀
- 상태: 실증 검증 전·미확정
- 사용자 최신 지시: “제작팀 결과가 오면 확인하고 전체 상세페이지를 염두하고 지시해.” 이어서 “검수는 필요없고 전달해.”

## 전달 사항

이번 후속 작업에는 디렉팅팀의 별도 검수·승인 대기 절차를 두지 않는다.
현재 제작 중인 결과는 저장하고, 전체 상세페이지에 활용할 다양한 연출컷 확보를 목표로 이어서 진행한다.
초기 C01~C03만으로 상세페이지 전체를 완성했다고 처리하지 않는다.
벽 명도·소품만 바꾸는 중복 비교는 필수 작업에서 제외한다. 기존 비교 실험·시도 제한은 이번 후속 제작의 필수 관문으로 적용하지 않는다.

## 컷 방향

| 역할 | 필요한 이미지 | 제작 방향 |
|---|---|---|
| 도입 | 제품 전체와 공간 인상을 보여주는 메인 | 제품이 중심이 되는 대표 연출 |
| 형태 이해 | 긴 변 중심, 짧은 변 중심, 높이를 달리한 사선 등 서로 다른 구도 | 실제 원본이 뒷받침하는 시점부터 제작. 같은 구도의 배경만 바꿔 수량을 채우지 않음 |
| 공간 맥락 | 가까운 제품 중심 장면과 넓은 공간 장면 | 동일한 무드 안에서 거리·여백·프레이밍을 달리함 |
| 사용 장면 | 의자·최소 소품을 포함한 다이닝 장면 | 확인된 제품 소스 활용, 식탁 특징을 가리지 않도록 구성. 좌석 수·실측 편의는 근거 없이 주장하지 않음 |
| 디테일 | 실제 상판 가장자리·다리·프레임 등 | 실제 원본으로 확인되는 부분 활용. 생성 디테일을 실물 증거로 설명하지 않음 |
| 옵션 | 확인 가능한 다른 옵션의 전체 모습 | 옵션을 섞지 않고 분리. 공식 대응이 미확인인 부분은 기록 |

우선 제품 원본으로 구현 가능한 서로 다른 구도를 제작하고, 필요한 구도에 자료가 없으면 해당 컷과 필요한 자료만 구체적으로 남긴다.
기존 제품 보존·선택 무드 방향은 유지한다. 이번 전달은 별도 검수 단계를 추가하라는 요청이 아니다.

## 저장·인계

제작팀이 본인 팀 결과 파일에 실제 시안·열람 가능한 이미지 경로·구도별 용도·남은 자료만 간결하게 기록한다.
사용자에게 실제 결과 이미지를 제시한다. 디렉팅 검수 대기를 이유로 후속 제작을 멈추지 않는다.
이 문서는 제작팀 수신이나 별도 세션 자동 실행을 의미하지 않는다.
상대 팀 파일·공통 지침·스킬은 수정하지 않는다.

## 변경 내용·이유·근거

- 변경: 초기 단일 구도·비교 중심 시험에서 전체 상세페이지용 구도 다양화와 실사용 컷 확보로 후속 방향 전달. 별도 디렉팅 검수 관문 생략.
- 이유: 사용자가 전체 상세페이지를 염두에 둔 제작 지시를 요구하고 검수 없이 전달하도록 명시.
- 근거: 현재 대화의 사용자 최신 두 지시. 제작 효과·고객 효과는 아직 검증하지 않았다.

## 재전달 v0.2 — 총 12컷 제작 명세 (2026-10-23)

이 절이 위 용도 분류를 컷별 수량으로 구체화한다. **최종 납품 목표는 서로 다른 이미지 총 12컷**이다.
12컷은 디렉팅팀의 이번 제작 배정 수량이며 사용자가 직접 지정한 숫자는 아니다. 전체 상세페이지용 이미지 확보를 위한 선택이다.
디렉팅팀 별도 검수·승인 대기 없이 진행한다. 벽 명도나 화병 유무만 다른 비교본은 아래 12컷의 별도 컷으로 세지 않는다.

|---|---|---|---|
| P01 | 1 | 메인, 긴 변 중심 3/4 전체 | 밝은 하부 29 기준, 제품 중심 무소품 |
| P02 | 1 | 짧은 변 중심 전체 | 01 기준, 네 다리 관계와 상판 깊이 전달 |

밝은 하부·검은 하부는 관찰 구분이다. 공식 판매 옵션과 현행 버전 대응은 아직 미확인이다.

### 실행을 가볍게 유지

- 이미 제작한 결과가 위 ID의 목적·구도에 맞으면 재사용하고 기존 파일·새 ID 대응만 기록한다. 무조건 12장을 새로 생성하라는 뜻은 아니다.
- 가능하고 근거가 있는 컷부터 이어서 제작한다. 컷마다 필요한 제품 입력과 하나의 구도 지시를 사용하고 문서·비교본을 반복 생산하지 않는다.
- 실제 원본으로 충분한 P09~P11은 원본 활용을 우선한다. 픽셀 부족 시 무리한 디테일 복원을 하지 않는다.
- P01~P05/P07~P08/P12는 가로형, P06은 세로형, 디테일은 내용에 맞는 비율을 쓴다. 전달본은 긴 변 1600px JPG를 기준으로 하되 부족한 원본은 확대 여부·실제 크기만 기록한다.
- 동일한 공간 무드·제품 외형을 유지하고 새 시점에서 확인되지 않는 구조를 사실처럼 확정하지 않는다.
- 필요한 시점·의자 소스가 없으면 해당 컷만 자료 부족으로 표시한다. 다른 컷 제작은 계속한다.
- 대체가 필요하면 확인 가능한 같은 제품의 다른 정보 목적·공간 프레이밍으로 제안하되 원래 컷과 대체 컷을 기록한다. 미제작을 완료로 세지 않는다.
- 총 12컷 중 원본 활용·기존 결과 재사용·신규 생성 수를 간단히 구분한다. 확대·재크롭·리사이즈만 다른 파일은 새로운 컷으로 세지 않는다.
- 결과 이미지를 사용자에게 바로 제시하고 묶음 파일과 컷별 용도 목록을 저장한다. 디렉팅 별도 검수표·승인 절차는 요청하지 않는다.
