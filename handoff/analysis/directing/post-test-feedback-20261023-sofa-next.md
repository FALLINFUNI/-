# 디렉팅팀 — 식탁 단품 사용자 평가 및 다음 소파 테스트 인계

- 날짜: 2026-10-23 (한국 시간)
- 상태: **실증 검증 전·미확정**
- 사용자 제작 요구 변경은 다음 테스트부터 적용한다. 공통 지침·스킬 채택이나 효과 검증 완료를 뜻하지 않는다.
- 현재 이미지를 디렉팅팀이 추가 검수한 기록이 아니라 사용자가 직접 확인하고 전달한 평가다.

## 사용자 평가와 다음 시험 요구

- 식탁 단품 결과는 나쁘지 않으며 특히 배경이 괜찮다는 사용자 평가.
- 디테일 컷이 부족하고 두 컬러 중 크림색 위주라는 사용자 지적.
- 식탁 단품은 총 12컷에서 **총 24컷**으로 조정.
- 옵션이 있으면 옵션별로 컷을 배정하고 디테일 부위·구도를 다양화.
- 예시로 준 디테일만 반복하지 말고 다른 부위·구도 제작 가능성도 확인.
- 같은 공간·배경·빛 조건을 유지.
- 테스트 뒤 내린 지시를 기록하고 다음 테스트부터 적용.
- 다음 제품 테스트는 **소파 우선**, 식탁 세트 테스트는 이후에 진행.
- 별도 디렉팅 검수·승인 대기 관문은 추가하지 않는다.

## 식탁 단품 24컷 배정 후보

두 옵션이면 옵션당 12컷씩, 각 옵션 전체·공간 4 + 디테일 8로 배정하는 안을 제안한다.
이는 총 24컷·옵션별 제작·디테일 확대라는 사용자 요구를 실행하기 위한 디렉팅 후보안이며 옵션별 세부 배정은 아직 확정하지 않았다.
각 옵션 12컷에 동일한 부위·구도 역할을 대응해 비교 가능하게 하되, 같은 이미지의 단순 재크롭을 독립 촬영 구도로 세지 않는다.
디테일 후보: 상판 끝 전체 곡률 / 가장자리 단면 / 상판·프레임 경계 / 다리 상부 연결 / 원기둥 다리 측면 / 다리 끝·접지 / 긴 프레임·다리 관계 / 짧은 프레임·다리 관계.
실제 보이는 구조와 원본 해상도가 뒷받침하는 항목만 실행한다. 소재·접합부 내부를 상상해 사실로 제시하지 않는다.
검은 하부 옵션에 크림 하부 디테일을 그대로 색만 바꿔 확정 제품처럼 전용하지 않는다.
옵션이 더 많으면 총 24컷 안의 배분과 정보 충족 여부를 다시 정한다. 자동으로 옵션당 24컷으로 해석하지 않는다.

## 새 디테일·구도 제작 가능성 판단

생성 도구로 첨부에 없는 구도를 시도하는 것은 가능하다. 다만 실제 제품과 일치한다고 보장할 수는 없다.
지금은 가능성 분석만 했으며 실제 생성 시험을 실행한 것은 아니다.

| 구분 | 예시 | 실행 방향 |
|---|---|---|
| 이미 보이는 부위의 화면 구성 변경 | 원본에서 확인되는 다리·프레임을 가까이, 여백·촬영 범위 변경 | 해상도와 형태 근거가 충분하면 우선 시도. 단순 확대는 새 구조 근거 아님 |
| 확인된 외형의 새로운 시점 | 사선 방향·높이 변화 | 제품 원본을 계속 참조. 보이지 않는 면이 드러나는 범위를 표시하고 불확실성을 기록 |
| 확인되지 않은 세부 | 하부 체결 방식·뒷면·재봉선·미세 표면·바닥 부속 | 정확한 실물 표현이 목적이면 해당 부위 사진 요청. 그럴듯한 창작으로 대체하지 않음 |

필요 자료는 전체를 다시 요구하지 않고 실제로 없는 부위·옵션·방향만 특정한다.
생성된 디테일은 실물 시험·재질·내구성의 증거가 아니다.

## 배경과 조건 유지

기준 공간 이미지를 하나 정하고 벽·바닥·창/고정물 위치·빛 방향·시간대·전체 톤을 공유한다.
카메라가 바뀌면 같은 장소에서 달리 보이는 것이므로 화면 픽셀을 동일하게 강제하지 않는다.
옵션을 바꾸면서 배경·노출·화이트밸런스를 임의로 바꿔 제품 색 비교가 어려워지지 않게 한다.
상세 컷도 같은 장소에서 촬영한 듯한 빛·톤을 목표로 한다. 원본 디테일의 조건이 다르면 이를 무리하게 재생성해 실물 근거를 잃지 않도록 제작 방식을 구분한다.

## 다음 소파 시험 준비

순서: 현재 식탁 결과의 6단계 평가에 사용자 피드백을 포함해 기록 → 소파의 레퍼런스 기반 경량화 시험 → 식탁 세트 시험.
현재 6단계 전체 완료를 선언하지 않는다.
소파는 선택 모델·색상 옵션·좌우형/카우치/모듈 구성과 원본을 확인한 후 컷표를 만든다.
전체·측면·등받이/팔걸이·좌방석·하부/다리·실제 원단/봉제 등은 해당 제품 구조에 맞춰 배정한다.
식탁의 24컷 조건을 소파에 자동 적용하지 않는다. 소파는 자료·옵션·용도를 확인한 뒤 제작 수량을 명시한다.
디렉팅 입력은 제품·옵션표 + 공간 레퍼런스 + 짧은 컷표로 간소화한다.
이번 기록만으로 소파 이미지를 생성하거나 모델을 임의 선택하지 않는다.
