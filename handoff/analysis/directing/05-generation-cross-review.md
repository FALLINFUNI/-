## 대상과 목적
오르보 식탁을 예시로 생성 성공률과 검수 정확도를 분리해 개선하는 방법을 분석했다. 잘못된 제품을 통과시켜 통과율만 높아지는 것을 개선으로 보지 않는다. 제품 정확성·공간 연속성·사진 완성도·구매 정보 전달을 각각 검토하는 방안을 제안했다. 이번 작업에서는 이미지를 생성하지 않았다.

## 1. 생성 입력과 판정 범위 — 후보
- 컷별로 제품 원본, 옵션·버전, 공간 기준, 해당 시야의 참조, 촬영 목적, 필수 가시 부위, 변경 범위와 미확인 사항을 연결한다.
- 오르보의 확인 대상 후보: 상판 윤곽, 상판과 프레임의 경계, 다리 형태·배치, 색 조합.
- 정확한 치수·소재·버전 등 미확인 정보는 생성과 검수에서도 사실로 취급하지 않는다.
- 제품 참조와 공간 참조의 역할을 구분한다. 이전 생성물을 참조해도 제품 원본과 계속 대조하는 방법을 시험한다.
- 필수 부위가 가려졌다면 제품 오류 여부는 판단 보류로 두되, 컷의 정보 전달 목적은 미충족으로 구분한다.

## 2. 컷별 제작 방법 — 비교 시험 후보
| 조건 | 시험 방향 | 주요 위험 |
| --- | --- | --- |
| 원본과 같은 시야 | 원본 제품 보존을 우선한 공간 제작 | 제품과 공간의 빛·원근 불일치 |
| 새로운 시야 | 해당 방향 실물 근거를 참조한 제작 | 상판·다리·하부 구조 변형 |

방법은 제품 보존·사진 완성도·수정 비용으로 비교한다. 전체 세트 이전에 실패 위험이 큰 시야를 시험하되, 대표 컷 하나의 성공을 전체 세트 성공으로 해석하지 않는다.

## 3. 교차 검수 — 독립 판정 후보
- 원본 ↔ 생성물: 같은 제품·옵션인지.
- 공간 기준 ↔ 생성물: 설계한 장소와 배치인지.
- 생성물 ↔ 생성물: 세트 안의 제품·공간에 모순이 없는지.
- 컷 기획 ↔ 생성물: 필요한 정보가 실제로 보이는지.

제품 정확성, 공간 연속성, 사진 완성도, 구매 정보 전달을 따로 판정한다. 아름다운 분위기로 제품 변형을 상쇄하지 않는다. 컷끼리 일치해도 모두 원본과 다르면 실패로 본다. 전체 화면과 확대 화면에서 각각 확인한다. 정상적인 원근·반사·가림과 오류를 구분하며 단순 픽셀 차이를 제품 변형으로 단정하지 않는다.

판정 상태 후보: 통과 / 수정 / 판단 보류. 각 판정에 결과 파일·문제 위치·비교 원본·차이·확인 한계를 연결한다. 확인 불가를 통과로 취급하지 않는다.

## 4. 협업 — 시험 후보
제작팀은 자체 검수를 제출하고 디렉팅팀은 그 결론을 보기 전에 독립 판정을 작성한 뒤 근거를 대조하는 방식을 시험한다. 의견 일치 자체는 정확성의 증명이 아니다. 해소되지 않은 항목은 추가 자료 또는 사용자 확인으로 연결한다. 기획 자체의 오류도 디렉팅팀이 점검한다.

## 5. 수정과 재검수 — 후보
- 입력 오류: 원본·옵션 연결부터 수정.
- 기획 충돌: 컷 지시 수정.
- 생성 오류: 참조·지시·제작 방법 재검토.
- 근거 부족: 추가 자료 확보 또는 해당 컷 보류.

수정 대상과 근거를 구체적으로 기록한다. 수정 후 해당 부위뿐 아니라 다른 제품 부위와 세트 전체에서 새 오류를 확인한다. 결과를 덮어쓰지 않고 수정본을 구분한다. 반복 실패 시 중단·방법 변경 조건을 시험 전에 설계한다. 무제한 재생성으로 성공처럼 보이게 하지 않는다.

## 6. 실증 검증 계획 — 미실행
1. 생성 방법 시험: 제품·공간·컷 조건을 맞춰 방법을 비교하고 실패를 포함한 전체 시도를 기록한다.
2. 검수 능력 시험: 정상·결함·판단 불가 자료를 섞어 오류 누락과 정상 결과의 잘못된 탈락을 확인한다. 평가 기준 개발 자료와 평가 자료를 구분한다. 결함의 근거도 별도로 확인해야 한다.
3. 세트 완성 시험: 필요한 정보 누락과 컷 간 모순을 확인한다.

기록할 지표 후보: 최초 통과율, 최종 세트 완성률, 검수 누락, 수정 횟수, 시간, 비용. 각 지표의 분모·평가 단위·제외 조건·시험 횟수는 시행 전에 별도 정의한다. 기준 완화나 어려운 컷 제외로 생긴 통과율 상승을 구분한다. 임의 목표 성공률과 통과 점수를 확정하지 않았다. 검수 성능과 판매 효과는 별도 검증 대상이다.
