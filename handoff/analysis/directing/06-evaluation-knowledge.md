## 사용자 결정

## 목적과 범위
오르보 식탁을 예시로 무엇을 배웠다고 인정할지, 어떤 조건에서 재사용할지, 지식 축적 자체가 제작 성과와 고객 판단에 도움이 되는지 확인하는 방법을 검토했다. 단일 성공이나 원인 추정을 공통 사실로 확정하지 않는다. 이미지는 생성하지 않는다.

## 1. 평가 영역 분리 — 후보
5단계는 개별 이미지와 세트를 검수한다. 6단계는 여러 결과를 모아 방법의 효과와 적용 범위를 판단한다.
- 정확성: 제품 보존, 공간 연속성, 필요한 정보 충족.
- 재현성: 반복 제작 또는 다른 담당자의 실행에서도 유지되는지.
- 효율: 전체 시도, 수정, 검수에 든 시간과 비용.
- 고객 효과: 이해, 구매 판단, 실제 구매 행동, 실물 기대 일치.
네 영역을 하나의 평균 점수로 합치지 않는 방식을 시험한다. 품질 통과를 판매 효과 입증으로 해석하지 않는다. 속도 개선과 제품 오류 증가가 동시에 발생하면 각각 기록한다.

## 2. 작업 기록과 지식 항목 분리 — 후보
작업 기록에는 목표, 제품·옵션·버전·원본, 공간·컷·제작 조건, 전체 실제 결과, 판정 근거, 수정 이력, 최종 상태를 연결한다. 성공뿐 아니라 실패·보류·중단·제외 사유를 남긴다. 수정본은 최초 생성과 연결한다.

지식 항목의 최소 구성 후보:
발견 / 근거 / 적용 조건 / 반례 / 미확인 사항 / 상태 / 버전 / 재검증 조건.

짧은 지식에서 원본 작업 기록으로 돌아가 확인할 수 있게 한다. 밝은 하부와 검은 하부, 전체 컷과 접사 등의 조건을 구분한다.

## 3. 관찰·원인 후보·시험 결과 구분 — 후보
- 관찰은 실제 결과에서 확인된 현상만 기록한다.
- 원인은 가설로 표시하고 대안 원인을 함께 검토한다.
- 효과는 비교 조건과 시행 결과를 근거로 판단한다.
- 재사용 범위는 확인한 제품·옵션·구도·공간·방법 안에서 먼저 제한한다.

가상 예시: 밝은 다리 윤곽이 잘 보이지 않았다면 배경 밝기·노출·빛·제품 변형 등을 원인 후보로 구분한다. 조건을 통제한 시험 전에는 밝은 배경 금지 같은 규칙을 만들지 않는다. 이 예시는 실제 시험 결과가 아니다.

## 4. 상태와 적용 범위 — 후보
상태 후보: 관찰 / 가설 / 시험 중 / 조건부 검증 / 보류 / 폐기.
적용 범위 후보: 제품·옵션 한정 / 공간·구도 한정 / 제작 방법 한정 / 공통화 후보.

오르보에서의 결과를 다른 식탁이나 소파에 자동 적용하지 않는다. 제품 리뉴얼, 원본 교체, 제작 도구 변경 시 재검증 필요 여부를 확인한다. 반례가 나오면 적용 범위를 좁히거나 보류하고, 이전 판단과 변경 이유를 함께 보존한다. 새 기록은 검색·비교 자료로 활용하며 공식 지침에 자동 편입하지 않는다.

## 5. 평가 기준 신뢰성 — 시험 후보
비교 시험에서는 판정 기준을 고정하고, 기준이나 담당자가 달라졌다면 기존 결과와 구분한다. 평가 기준 변경 자체도 기록한다. 지표별 분모·평가 단위·제외 조건을 정의하고 일부 사례만으로 정밀한 성공률 또는 공통 효과를 주장하지 않는다.

## 6. 지식 축적의 실효성 검증 — 미실행
1. 지식을 사용하는 조건과 기존 방식의 조건을 비교한다.
2. 기준 개발에 사용하지 않은 컷·공간에서 재사용 효과를 확인한다.
3. 정확성·수정량·전체 시간·비용을 함께 비교한다. 기록 검색·열람·관리 시간도 포함한다.
4. 고객 시험에서는 이미지 선호도, 제품 이해, 미해결 질문, 구매 행동을 구분한다.
5. 가격·혜택·유입 등의 차이를 관리하고 클릭 증가만으로 구매 효과를 확정하지 않는다.
6. 사진으로 인한 제품 오해나 실물 기대 불일치도 평가한다.

시험 대상·비교 조건·판정 기준·시행 횟수와 고객 데이터 수집 방법은 실행 전에 별도 설계한다. 이번 기록에서는 목표 수치나 통과 기준을 확정하지 않았다.
