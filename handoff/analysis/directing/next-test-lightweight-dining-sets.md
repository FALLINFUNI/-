## 확인된 요구

판매 단위는 식탁 단품뿐 아니라 의자·벤치와 조합한 식탁 세트다.
단품 사진을 유지하면서, 메인 의자로 구성한 세트 사진과 추가 옵션 의자로 구성한 세트 사진을 각각 여러 장 확보해야 한다.
의자는 최소 두 가지 서로 다른 종류를 사용한다. 동일 의자의 색상 차이만으로 두 종류를 충족했다고 처리하지 않는다.
벤치를 포함하는 세트도 다룬다. 실제 판매 조합·벤치 선택 여부·소스는 시험 착수 시 확인한다.
추가 의자 옵션은 우선 세트별로 분리해 보여준다. 실제 판매 구성이 확인되지 않은 의자 혼합 세트를 임의로 만들지 않는다.
고객의 실제 선택 이유는 자료가 없으면 가설로 남긴다.

## 2·3·4단계에서 드러난 문제

| 단계 | 이번 진행에서 확인된 문제 | 원인 후보 | 다음 시험의 개선 |

문제와 누락은 기존 지시 및 사용자 피드백에서 확인한 사실이다. 위 원인은 가설이며 경량화가 품질·속도를 개선하는지는 다음 시험에서 확인한다.
현재 제작 이미지에 대한 추가 검수를 수행했다는 뜻은 아니다.

## 레퍼런스를 이용한 2·3·4단계 경량화 후보

레퍼런스를 직접 열고 아래 네 항목만 추려 제작에 연결한다.
1. 세트 구성: 식탁 / 메인 의자 A / 추가 옵션 의자 B 이상 / 해당 벤치.
2. 유지할 연출: 공간 톤 / 빛 / 구도·소품 중 필요한 요소.
3. 바꿀 것: 실제 제품·세트 조합 및 원본과 맞지 않는 부분.
4. 컷표: ID / 세트 조합 / 구도 / 용도 / 수량 / 필요한 소스.

레퍼런스와 겹치는 무드 설명을 길게 반복하지 않는다.
2단계는 이번 컷이 답할 구매 질문만 짧게 연결한다. 레퍼런스가 고객 동기·제품 성능의 증거가 되는 것은 아니다.
3단계는 레퍼런스를 공간 기준으로 삼고 복잡한 공간 명세는 충돌이 있을 때만 보완한다.
4단계는 단품·메인 세트·추가 옵션 세트를 구분한 컷표 한 장을 제작 입력으로 사용한다.
가격·실측·소재·성능·판매 옵션은 사진에서 만들어내지 않는다.

## 다음 테스트의 잠정 컷 배정

아래 수량은 디렉팅 제안이다. 사용자가 직접 지정한 수량이 아니다.
소스 확인 후 테스트 시작 전에 동일 파일에서 실행 배정을 정하고 기록한다.

| 묶음 | 최소 제안 수량 | 구도·내용 |
|---|---|---|
| 식탁 단품 | 2 | 전체 사선 + 다른 방향 전체 |
| 식탁 + 메인 의자 A | 3 | 메인 세트 사선 + 짧은 변 방향 + 넓은 공간 |
| 식탁 + 추가 옵션 의자 B | 3 | A와 대응하는 세 구도. 의자 차이가 읽혀야 함 |
| 식탁 + 의자 + 벤치 | 3 | 벤치가 보이는 사선 + 반대쪽/짧은 변 + 공간 전체. 실제 구성 확인 후 적용 |

의자 두 종류를 쓰는 기본 범위는 8컷, 벤치 조합까지 포함하면 잠정 11컷이다.
의자 C 등 추가 옵션은 조합당 여러 구도를 별도 배정한다.
수량은 서로 다른 이미지 기준이다. 단순 재크롭·리사이즈·소품 하나 변경은 추가 구도로 세지 않는다.
한 세트의 결과만 확보하고 다른 의자 조합을 빠뜨린 상태를 세트 테스트 완료로 표시하지 않는다.

## 착수 시 확인할 최소 자료

사용자가 제공하는 레퍼런스, 선택 식탁 원본, 의자 A/B 각각의 식별 가능한 원본, 벤치 포함 시 해당 원본과 실제 판매 조합.
연결된 자료에서 먼저 확인하고 부족한 제품·구도만 구체적으로 요청한다.
모델·색상·버전을 섞지 않는다. 의자 A/B와 벤치는 자료 확인 전 임의 제품명으로 배정하지 않는다.
새 시점의 제품 재현에 필요한 근거가 없으면 해당 컷만 표시하고 가능한 컷은 이어서 제작한다.

## 경량화 테스트에서 남길 최소 결과

기존 방식과 레퍼런스 중심의 간결한 지시를 비교할 때 제품·조합·컷 목적을 맞춘다.
기록: 실제 지시 분량, 사용 자료 수, 인계 횟수, 실제 작업 시간(측정 시), 생성·수정 횟수, 전달 이미지 수, 구도·조합 누락, 사용자 피드백.
단순 작업량 축소를 효율 향상으로 주장하지 않는다. 입력·기록 작성에 든 시간도 포함한다.
별도 디렉팅 이미지 검수 관문은 추가하지 않는다. 제작팀 수행 기록과 사용자 피드백에서 문제를 수집한다.
문제마다 발생 단계 / 관찰 / 영향 / 원인 가설 / 개선 / 재시험 결과를 남긴다.
이전 방식의 비교 가능한 측정값이 없으면 전후 효과는 미측정으로 기록하고 새 시험을 기준선으로 둔다.
