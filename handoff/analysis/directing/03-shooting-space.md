## 대상과 목적
오르보 식탁을 예시로 제품 가독성, 실제 배치 가능성, 여러 컷의 공간 연속성, 반복 제작 가능성을 함께 고려하는 촬영 공간 설계 방법을 검토했다. 첨부 사진의 기존 배경을 향후 공간으로 확정하지 않는다. 제품의 정확한 치수·옵션·구성·구매 이유가 미확인이라면 관련 공간 설계도 잠정안으로 둔다.

## 분석안 — 검증 전
### 1. 제작 방식과 원본 제약을 먼저 확인
- 원본 제품 사진을 보존해 활용하는 경우 카메라 높이·원근·빛과 공간의 적합성을 확인한다.
- 새로운 방향을 제작하는 경우 해당 방향의 제품 근거와 공간 근거를 구분해 확보한다.
- 공간 자료가 있어도 제품의 보이지 않는 구조가 확인되는 것은 아니다.

### 2. 분위기·구조·빛·촬영 범위를 분리해 설계
- 분위기: 색 조합, 재질, 소품, 생활감과 전달할 인상.
- 구조: 방 크기, 벽·창·출입구·가구의 위치 관계.
- 빛: 광원 위치·방향·퍼짐·보조광과 제품 가독성.
- 촬영 범위: 카메라 위치·높이·이동 가능 구역과 필요한 시야.
- 무드 문장 외에 배치도와 방향별 공간 참조를 사용하는 방법을 시험한다. 참조만으로 생성 일관성이 보장된다고 판단하지 않는다.

### 3. 오르보의 제품 가독성 점검 후보
- 상판 외곽이 배경선·소품·그림자에 가려지지 않는가.
- 상판과 하부 프레임 경계가 구분되는가.
- 원통형 다리의 형태를 읽을 수 있는가.
- 밝은 하부와 검은 하부 옵션을 각각 평가하는가.
- 공간색과 빛으로 인해 제품 옵션을 오인할 가능성이 있는가.
- 색 판단을 위한 실물 기준 컷과 분위기 연출컷을 구분한다.

### 4. 실제 사용 조건 안에서 생활감 설계
- 식탁·의자·식기 크기는 확인된 자료를 기준으로 검토한다.
- 의자를 빼고 앉는 공간과 주변 가구 간 간격을 확인한다.
- 소품마다 목적을 부여하고 제품 특징을 가리는지 확인한다.
- 실측·의자 구성 미확인 상태에서 착석 인원·사용 여유·공간 효율을 확정하지 않는다.

### 5. 고정 항목과 변경 범위
- 세트 고정 후보: 방 구조, 창 위치, 벽·바닥 마감, 기준 가구 배치, 시간대와 광원 조건.
- 컷별 변경 후보: 카메라 위치, 촬영 범위, 지정된 의자·소품 상태.
- 변경은 기록해 기획된 변화와 생성 오류를 구분한다.
- 다른 시야의 그림자나 반사를 화면상 동일하게 강제하지 않고, 같은 광원 조건으로 설명되는지 검토한다.

## 검증 계획 후보 — 미실행
1. 배치 검증: 실측 기준으로 사용과 촬영이 가능한지 확인한다.
2. 제품 가독성 검증: 윤곽·색·구조를 제품 근거와 대조한다.
3. 다중 시야 검증: 대표·측면·반대 방향에서 공간 요소의 위치 관계와 제품 배치가 이어지는지 확인한다.
4. 반복 제작 검증: 같은 설계로 반복했을 때 성공·실패와 수정 횟수를 기록한다. 단일 우수 결과만으로 통과를 선언하지 않는다.
5. 조건 비교: 배경 또는 빛 등 비교 변수를 제한해 문제 감소 여부를 확인한다.
