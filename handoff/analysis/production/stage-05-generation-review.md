**상태: 실증 검증 전·미확정**

본 파일은 제작팀 수행 역할의 분석 보존본이다. 기존 분석 시점의 ‘미실행’ 표현은 당시 상태를 보존한다. 최신 실행 상태는 아래 관리 기록과 연결된 테스트 결과로 구분한다.

# 5단계 생성·교차 검수 — 검증 전 후보 기록

- 기록일: 2026-10-23 (Asia/Seoul)
- 예시 제품: 사용자가 제시한 오르보 식탁 사진 5장
- 상태: 분석·브레인스토밍 후보. 테스트 및 실증 검증 미완료. 공식 기준 아님.
- 사용자 결정: 테스트·실증 검증 후 구조 개선·시스템화·확정 여부를 판단한다. 현재는 기록만 한다.
- 이번 작업: 이미지 생성·테스트 실행·공식 지침·스킬·시스템 변경 없음.

## 목적
원본과 같은 제품을 유지하며 상세페이지에 함께 사용할 사진 세트를 반복해서 확보한다. 생성 방법과 검수 방법을 각각 검증해야 하며, 검수가 부정확하면 생성 성공률도 왜곡될 수 있다.

## 생성 전에 비교 기준을 고정하는 안
| 기준 | 용도 |
|---|---|
| 제품 원본·확인된 사양 | 형태·구조·옵션 정확성 |
| 공통 공간 자료 | 벽·창·배치·빛의 관계 |
| 컷별 요청서 | 구도·가시 부위·구매 질문 전달 여부 |

생성 기준 컷은 공간·분위기 참고가 될 수 있으나 제품 원본을 대체하지 않는다. 생성물만 연속 참조하면 초기 오류가 다음 컷에 전파될 가능성을 검증해야 한다. 컷 간 일관성만으로 원본 정확성을 인정하지 않는다.

## 원인 구분과 대응 후보
| 원인 | 예 | 대응 |
|---|---|---|
| 입력 부족·충돌 | 밝은 프레임과 검은 프레임 옵션 혼합 | 자료와 옵션 대응 정리 |
| 생성 오류 | 원본에 없는 상판 곡선·프레임 | 참조·지시·제작 방식 재검토 |
| 컷 설계 문제 | 의자가 다리를 가려 목적 부위를 확인할 수 없음 | 구도·배치 조정 |
| 검수 오류 | 원근·명암 차이를 변형으로 오판 | 비교 조건과 근거 재검토 |

원인 확인 없이 프롬프트에 조건만 계속 추가하는 방법을 기본 해법으로 확정하지 않는다.

## 네 가지 검수 축
1. 제품 정확성: 상판 윤곽·가장자리, 다리 단면·두께·배치·하단, 프레임 연결, 확인된 옵션.
2. 촬영 지시 준수: 필요한 부위 노출, 제품 크기·구도·소품, 컷 목적.
3. 사진 자연스러움: 접합부, 바닥 접촉, 그림자·반사, 원근, 표면 연속성.
4. 세트 일관성: 제품·옵션·색·공간 관계가 각 컷에서 설명되는가.

전체 인상, 부위 확대 대조, 모바일 표시 크기의 정보 전달을 구분해 확인하는 안이다. 제품 오류를 분위기 점수로 상쇄하지 않는다. 후보 전부가 부적합하면 채택 없음으로 기록한다.

## 관찰과 판정 구분
- 확인됨: 근거 자료와 비교해 일치 판단 가능.
- 불일치: 구체적인 차이를 근거와 함께 확인.
- 판단 보류: 원본 부족·가림·해상도 등으로 확인 불가.

다리 4개 제품에서 사진에 3개만 보이는 경우는 가림 관계를 확인한다. 보이는 개수만으로 오류로 판정하지 않으며, 보이지 않는 다리가 정확하다고 통과시키지도 않는다. 해당 부위를 보여주는 것이 컷 목적이라면 가림은 컷 목적 미달이다.

서로 다른 구도의 픽셀 두께·색상값을 그대로 실제 비례·고유색 차이로 판단하지 않는다. 원근·빛·가림을 고려하되 이를 모든 불일치의 설명으로 남용하지 않는다. 정확한 형상·치수·공식 색·재질·사진 간 옵션 대응의 미확인 사항은 1단계와 연결한다.

## 생성·수정 흐름 후보
- 확인하기 쉬운 전체컷 → 다른 방향 전체컷 → 원본 근거가 충분한 디테일컷으로 확장.
- 확장 시에도 제품 원본을 계속 참조.
- 수정 지시에는 오류 위치·원본 근거·요청 변경·유지 조건을 명시.
- 수정 후 해당 부위, 제품 전체, 관련 다른 컷과의 관계를 다시 검토.
- 반복 수정으로 다른 특징이 변하면 원본에서 재시작하는 방식과 비교. 재시도 횟수 제한은 미확정.

## 검수 방식 자체의 검증 제안 — 미실행
정상 사례와 오류 사례를 섞어 실제 오류 누락, 정상적인 원근·명암 차이 오판, 자료 부족 상태의 무근거 통과를 확인한다. 가능하면 제작자의 의도 설명 전에 원본과 결과로 판정하고, 담당자 간 판단 차이를 기록한다. 판정 기준을 조정한 뒤에는 그 기준 조정에 사용하지 않은 사례로 재확인하는 안을 검토한다.

검수 기록에는 문제 위치·비교 원본·관찰 차이·판정·수정 후 재검사 항목을 남긴다. 자동 검사·AI 평가는 보조이며 세부 제품 정확성을 보장한다고 가정하지 않는다.

## 실증에서 기록할 지표 후보
| 대상 | 기록 |
|---|---|
| 생성 효율 | 전체 생성 수, 첫 시도 통과 여부, 시간·비용 |
| 수정 효과 | 수정 횟수, 해결 오류, 새 오류 |
| 검수 신뢰성 | 놓친 오류, 잘못 지적한 오류, 판단 보류 |
| 세트 완성도 | 필요한 컷 충족, 컷 간 충돌, 함께 사용할 수 있는 세트 여부 |

최종 채택물만 보관하지 않는다. 생성 시도·실패·수정 버전·참조 자료·지시·검수 결과를 연결해 남긴다. 개별 컷 통과율과 세트 완성률을 분리하고, 성공률을 계산하기 전에 평가 단위와 분모를 정한다. 비교 시험에서는 같은 입력·도구 조건에서 시험할 변경 요인을 분리한다. 현재 성공률·허용 오차·통과 점수·재시도 제한의 확정 수치는 없다.

## 근거와 적용 한계
- DreamBench++: https://arxiv.org/abs/2406.16855 — 대상 특징 보존과 지시 준수를 구분하는 평가 연구.
- GenEval: https://arxiv.org/abs/2310.11513 — 개수·위치·색 등 구체적 속성 평가 연구.
- 위 연구는 평가 설계의 참고이며 오르보의 정밀한 형상·구조·색 검수나 판매 효과를 검증한 근거가 아니다.

## 확정 보류
첫 실증 후보는 기준 전체컷·다른 방향 전체컷·디테일컷이며 제품 오류 감소, 검수 오류 탐지, 세트 완성을 별도로 평가한다. 지금은 실행하지 않는다. 시험 전에 판정 기준을 마련하고 테스트 → 오류·효과 분석 → 개선 → 재검증 후 확정 여부를 판단한다. 이 기록을 운영 지침·스킬·자동화 시스템에 즉시 반영하지 않는다.


## 관리 상태 및 변경 이력
- 담당 파일 소유: 제작팀. 상대 팀 파일은 참조만 하며 수정하지 않는다.
- 현재 상태: **실증 검증 전·미확정**. 원본 대조나 단일 시험 착수는 실증 완료가 아니다.
- 이번 파일은 분석 보존 문서이며 공통 지침·스킬·공식 시스템에 반영하지 않는다.
- 갱신 시 이 파일을 읽고 현재 내용과 변경 이력을 함께 수정한다. 검증 결과는 테스트 ID·결과 파일·커밋으로 연결한다. 기존 반례와 실패 이력은 삭제하지 않는다.
- 자동 감시나 다른 채팅 자동 실행은 설정하지 않았다. 후속 작업에서 변경을 확인했을 때 갱신한다.

|---|---|---|---|---|
| 2026-10-23 | 제작팀 소유의 단계별 분석 기록 최초 등록 | 사용자 요청에 따른 보존 및 변경 추적 | 이전 대화 분석·기존 기록·요청서 대조. 효과 실증 근거는 없음 | 반복 재현·독립 검수·고객 검증 미완료 |
