# 3단계 촬영 공간 설계 — 검증 전 후보 기록

- 기록일: 2026-10-23 (Asia/Seoul)
- 예시 제품: 사용자가 제시한 오르보 식탁 사진 5장
- 상태: 브레인스토밍·분석안. 공식 기준 아님. 테스트 및 실증 검증 미완료.
- 사용자 결정: 검증을 마친 뒤 구조 개선·시스템화·확정 여부를 판단한다. 지금은 기록만 한다.
- 이번 작업: 이미지 생성, 테스트 실행, 지침·스킬·시스템 변경 없음.

## 목적
제품이 돋보이고, 여러 구도가 하나의 실제 촬영 장소로 이어지는 공간을 설계한다. 제품 보존, 공간 일관성, 사진의 자연스러움, 고객 적합성을 구분해 평가한다.

## 관찰과 불확실성
첨부 사진에는 곡선이 있는 상판 외곽, 얇게 보이는 상판 가장자리, 원통형 다리 4개, 하부 프레임, 밝은 프레임과 검은 프레임이 보인다. 정확한 상판 형태·치수·재질·공식 색상·사진 간 옵션 대응은 미확인이다. 원본 배경은 새 공간의 정답으로 취급하지 않는다. 고객 취향과 판매 효과는 사진에서 확정하지 않는다.

## 설계 후보
1. 먼저 보여줄 제품 특징과 필요한 구도를 정하고, 제품 실측과 의자 사용 범위에서 공간 비례·촬영 거리를 검토한다. 컷 구성과 공간 설계는 상호 조정한다.
2. 배치(방·창·벽·출입구·제품·의자), 외관(색·재질·무늬·광택·소품), 촬영 조건(카메라 위치·높이·방향·빛·가시 범위)을 함께 작성한다.
3. 배치도, 시각 참고, 컷별 촬영 위치를 묶는다. 배치도나 분위기 사진 하나만으로 충분하다고 가정하지 않는다.
4. 창과 벽의 관계·마감·제품 크기와 기준 배치·방 안의 주광 방향은 유지한다. 원근·화면에 나타나는 창의 위치·반사·그림자는 구도에 맞게 달라질 수 있다.
5. 광원은 화면 좌우가 아니라 공간 기준으로 지정한다. 제품의 고유색 기준과 자연스러운 명암 차이를 구분한다.
6. 밝은 프레임은 배경과의 구분, 검은 프레임은 그림자 속 구조 가독성을 각각 확인한다. 소품과 의자로 상판 윤곽·다리·프레임이 가려지는지 확인한다.
7. 은은한 확산광에서도 다리 입체감과 상판 경계가 읽혀야 한다. 혼합광과 과도한 직사광을 초기 비교에서 단순화하는 안을 시험한다.
8. 첫 실험 후보는 단순한 다이닝 공간·한쪽 넓은 확산광·최소 소품이다. 검증 후 생활감과 장식을 추가하는 접근을 비교한다.

## 역할 협업 후보
디렉팅팀은 제품을 돋보이게 할 조건·공간 의도·평가 항목을 제안한다. 제작팀은 구현 가능성·자료 부족·생성 결과의 오류를 되돌려준다. 제품 파악과 결과 검토는 공동으로 수행한다. 역할 체계 자체도 미확정이다.

## 향후 테스트 제안 — 모두 미실행
| 시험 | 비교·방법 | 확인할 항목 |
|---|---|---|
| 생성 전 배치 검토 | 예정 카메라 위치·의자 사용·이동 공간 확인 | 벽을 없애거나 비현실적 이동 없이 촬영 가능한가 |
| 설계 정보 효과 | 같은 제품 원본·도구·컷 요청·출력 조건에서 분위기 설명만 제공한 조건과 배치·빛·촬영 위치를 추가한 조건 비교 | 구조 모순·제품 오류·수정 횟수·제작 시간 |
| 구도 확장 | 대표 사선·반대 사선·미들컷을 같은 공간으로 제작 | 창·벽·제품 위치·그림자의 관계가 설명되는가 |
| 반복 재현 | 각 조건을 반복하고 실패 결과도 보관 | 우연한 성공과 재현 가능한 개선을 구분할 수 있는가 |
| 제품 가독성 | 옵션별로 원본과 대조 | 색·상판 윤곽·비례·구조가 보존되는가 |

제안 평가 순서는 제품 보존 → 공간 모순 → 사진의 자연스러움 → 분위기 적합성이다. 치명적 제품 오류를 분위기 점수로 상쇄하지 않는 안을 검토한다. 시행 전에 반복 수·판정 기준·비교 조건을 정하며, 현재 성공률이나 통과 수치는 없다. 판매 효과는 별도의 고객 반응·판매 데이터 검증이 필요하다.

## 확정 보류
공간 설계의 정확성과 생성 도구의 재현 성능을 따로 평가한다. 테스트 결과 → 오류·효과 분석 → 개선 → 재검증 후 확정 여부를 판단한다. 이 기록을 곧바로 운영 지침·프롬프트 표준·자동화 시스템으로 승격하지 않는다.
