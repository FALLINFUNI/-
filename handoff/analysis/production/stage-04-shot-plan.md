- 기록일: 2026-10-23 (Asia/Seoul)

## 목적과 설계 단위
고객이 사고 싶어지는 장면과 제품을 정확히 판단할 수 있는 장면을 하나의 일관된 사진 세트로 구성한다. 컷 종류·수량 자체보다 정보 전달과 사진 간 모순 여부를 평가한다.

구매 질문 → 필요한 시각적 정보 → 촬영 방법을 연결한다. 풀샷·미들컷·디테일컷은 목적을 구현하는 수단이다. 컷마다 어느 부위를 얼마나 크게 보여줄지, 가림과 크롭은 어떻게 할지 명시하는 안을 검토한다.

## 오르보 예시의 질문과 컷 후보
| 구매 질문 | 보여줄 내용 | 후보·주의점 |
|---|---|---|
| 우리 집에 놓으면 어떤 인상인가 | 공간 속 전체 모습과 주변 가구 관계 | 대표 공간 풀샷. 공간이 식탁보다 먼저 보이지 않는지 확인 |
| 실제 디자인은 어떠한가 | 상판 윤곽·다리 수와 배치·하부 프레임 | 제품 중심 풀샷. 핵심 부위를 소품·의자가 가리지 않는지 확인 |
| 다른 방향은 어떠한가 | 앞 컷에서 가려진 면과 구조 | 보완 방향 풀샷. 새 정보가 있는 경우 포함 |
| 크기와 사용 공간은 어떠한가 | 확인된 치수·의자 비례·하부 공간 | 사용 맥락 컷과 별도 치수 이미지. 실측 없이 좌석 수·공간 여유를 확정하지 않음 |
| 가까이 보면 어떠한가 | 상판 가장자리·표면·다리 마감 | 핵심 디테일컷. 원본에서 확인되지 않는 질감·구조를 생성 근거로 확정하지 않음 |
| 어떤 옵션과 구성을 구매하는가 | 확인된 색·형태·사이즈 차이와 포함 상품 | 같은 조건의 옵션 비교. 조명 차이를 옵션 차이로 오해하지 않도록 검토 |

위 항목은 고정 6컷 공식이 아니다. 한 컷이 여러 질문을 해결하면 통합할 수 있고, 정보가 읽히지 않으면 분리한다. 고객 질문의 우선순위는 2단계의 실제 후기·문의 등 근거로 보완해야 한다. 제품 사진만으로 고객의 최우선 관심사를 확정하지 않는다.

## 성공률 향상을 위한 후보 방법
1. 제품 선택에 필요한 필수 정보와 분위기·사용 장면을 확장하는 보완 컷을 구분한다. 중요한 정보가 빠진 채 유사한 분위기 컷만 늘어나지 않도록 검토한다.
2. 컷마다 추가 정보와 세트 내 역할을 기록한다. 이 컷을 제거하면 어떤 판단이 어려워지는지 확인한다. 다른 각도여도 같은 정보면 중복일 수 있고, 비슷한 구도여도 역할이 다르면 필요할 수 있다.
3. 현재 자료로 만들고 검수할 수 있는 컷과 추가 원본이 필요한 컷을 구분한다. 확대 디테일은 원본 근거를 더 엄격히 확인한다.
4. 최종 모바일 표시 크기에서 특징이 읽히는지 확인한다. 제품 점유 크기·크롭·설명 여백을 컷 설계에 포함한다. 갤러리와 긴 상세페이지에 동일한 최적 순서가 있다고 가정하지 않는다.
5. 제품·공간을 확인하기 쉬운 기준 컷부터 제작하는 순서와 고객에게 제시할 순서를 분리해 시험한다.
6. 개별 컷의 완성도와 전체 세트의 제품·공간·옵션·색상 일관성을 별도 검수한다.
7. 사진은 배치와 외관을 설명할 수 있지만 편안함·내구성·내열성·흔들림·안전성을 단독 입증하지 않는다. 판매 구성과 연출 소품을 구분해 안내하는 안을 검토한다.

## 제작 요청에 포함할 최소 정보 후보
- 답할 구매 질문과 컷의 역할
- 반드시 보여야 할 부위와 필요한 크기
- 제품·옵션·근거 원본
- 공간·배치·구도·최종 크롭 조건
- 실패 판단: 변형·가림·정보 부족·중복·판매 구성 오해

디렉팅팀은 구매 질문과 컷의 의도를 제안하고, 제작팀은 구현 가능성과 원본 부족·촬영 제약을 피드백한다. 제품·공간 기준을 함께 검토한다. 역할 체계와 전달 형식도 검증 전 후보이다.

## 향후 테스트 제안 — 미실행
| 시험 | 방법 | 확인할 결과 |
|---|---|---|
| 정보 전달 | 고객이 사진 세트를 보고 형태·크기·옵션·포함 상품을 설명 | 실제 기준 정보와 일치하는가, 오해가 생기는가 |
| 누락 | 확인 후 남은 질문 수집 | 중요 구매 질문이 해결되지 않았는가 |
| 중복 | 특정 컷을 제외한 구성과 비교 | 이해도·분위기 전달·판단이 달라지는가 |
| 모바일 가독성 | 예정 표시 크기·크롭에서 확인 | 핵심 특징이 실제로 읽히는가 |
| 세트 일관성 | 각 컷을 원본 및 서로 대조 | 제품·옵션·색상·공간 관계가 유지되는가 |
| 효과 | 가격·문구·페이지 조건을 유지하고 컷 역할·추가 여부·순서를 분리해 비교 | 구성 변경의 영향과 다른 요인을 구분할 수 있는가 |

사진 품질·수량·순서를 동시에 바꾸면 원인을 판단하기 어렵다. 실패 결과도 남기고, 시험 전에 대상·반복 수·판정 기준을 정한다. 선호도·구매 의향은 실제 판매 개선을 입증하지 않는다. 현재 성공률·최적 수량·최적 순서·판매 효과 수치는 없다.
